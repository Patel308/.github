## About Me

I'm a **Data & AI Engineer** and technical founder who builds practical, production-grade systems at the intersection of cloud infrastructure, data engineering, and intelligent automation. My work spans the full stack — from designing distributed ETL pipelines and analytics platforms to deploying containerized applications and AI-powered business workflows.

Currently building [**Scallar IT Solutions**](https://scallar.in) — an AI automation and data engineering consultancy serving SMB clients across analytics, CRM, WhatsApp automation, and cloud transformation.

- 🏗️ I architect systems that **handle real production load** — not just demos
- 📊 I've built **analytics platforms** serving multiple live clients with PostgreSQL, dbt, and Metabase
- 🤖 I deploy **AI automation workflows** combining n8n, LLMs, and business-critical APIs
- 🌐 I run **scalable cloud infrastructure** on GCP with Docker, Nginx, and multi-service Compose stacks
- 🔍 I've engineered **large-scale web scraping systems** targeting 10,000+ business leads across USA and India
